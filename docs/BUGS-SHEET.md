# Bug Tracker

Report bugs here → [Imagine RPG Bug Form](LINK_TO_FORM)

View all bugs → [Imagine RPG Bug Sheet](LINK_TO_SHEET)

## Setup (one-time)

### 1. Create the Sheet

- Go to [Google Sheets](https://sheets.google.com)
- Create a new blank spreadsheet, name it **"Imagine RPG Bugs"**
- Add these headers in row 1:
  - **Timestamp** | **Category** | **Description** | **Screenshot** | **Suggested Fix** | **Minor Bugs** | **Status**

### 2. Create the Form

- Go to [Google Forms](https://forms.google.com)
- Create a new form, name it **"Report a Bug"**
- In the form settings:
  - Turn on "Collect email addresses" (optional)
  - Turn off "Show progress bar"
  - Turn off "Shuffle question order"

### 3. Add Form Fields

Create these questions in order:

1. **Category** (Required)
   - Multiple choice
   - Options: `1 - Feature not working` | `2 - Feature not performing` | `3 - Feature requested`

2. **Description** (Required)
   - Paragraph text
   - Placeholder: "Describe the bug in detail"

3. **Screenshot** (Recommended)
   - File upload
   - Allowed file types: Images
   - Instructions: "Upload a screenshot (optional but helpful)"

4. **Suggested Fix** (Optional)
   - Paragraph text
   - Placeholder: "If you have an idea how to fix this, share it here"

5. **Minor Bugs** (Optional)
   - Paragraph text
   - Placeholder: "Report multiple minor issues here, separated by new lines (e.g., button text is cut off / typo on page 3 / tooltip missing)"

### 4. Link Form to Sheet

- Click the "Responses" tab
- Click the green sheet icon
- Create a new sheet or select your existing one
- Google will auto-populate responses

### 5. Share the Form

- Click "Send" (top right)
- Copy the link
- Update `LINK_TO_FORM` above

## Categories

- **1** — Feature not working
- **2** — Feature not performing as desired  
- **3** — Feature requested

## How to report a bug

1. Open the [bug form](LINK_TO_FORM)
2. Select a category from the dropdown
3. Describe the bug (be specific)
4. Upload a screenshot if possible
5. *Optional:* Suggest a fix if you have an idea
6. *Optional:* List multiple minor bugs in the "Minor Bugs" field (one per line)
7. Submit

Done! The sheet updates automatically.

## Screenshots folder

Uploaded screenshots are stored in Google Drive. Create a folder in your shared drive:

```
Google Drive / Imagine RPG / Screenshots /
```

When screenshots are uploaded via the form, move them to this folder and update the "Screenshot" column in the sheet with the file link.
